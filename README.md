# DataTable Services for Laravel

A comprehensive package for managing DataTables in Laravel applications with advanced filtering and bulk operations support.

## Features

- 🚀 **Advanced DataTable Configuration** - Simplified HTML builder configuration
- 🔍 **Powerful Filter System** - Support for complex search criteria with nested groups
- 📅 **Smart Date Filtering** - Multiple date format support
- ✅ **Multi-page Selection** - Checkbox selection across pages
- 🔄 **Row Reordering** - Drag-and-drop row reordering
- 📤 **Export Options** - Excel, CSV, PDF, Print, and Copy exports
- 🎯 **Bulk Actions** - Easy bulk operation implementation
- 🌍 **Multi-language** - Support for multiple languages
- 🎨 **Customizable** - Highly configurable

## Requirements

- PHP >= 8.0
- Laravel >= 9.0
- Yajra DataTables >= 10.0

## Installation

```bash
composer require solaroberto/datatable-services
